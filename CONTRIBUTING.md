# Cómo contribuir a TechToJob

¡Gracias por querer aportar! TechToJob lo construimos entre todos y cualquier ayuda suma.

## Antes de empezar

1. Únete al [Discord](https://discord.gg/pzCa8esFGA). Ahí se coordinan los equipos, se vota y se resuelven dudas.
2. Lee el [código de conducta](CODE_OF_CONDUCT.md).
3. Busca en los issues si lo que quieres hacer ya está abierto o en marcha.

## Flujo de trabajo

1. Haz un fork del repo (o crea una rama si eres miembro de la organización).
2. Nombra la rama según el tipo de cambio:
   - `feat/descripcion-corta` para funcionalidades nuevas
   - `fix/descripcion-corta` para correcciones
   - `docs/descripcion-corta` para documentación
3. Haz commits pequeños y con mensajes claros. Seguimos [Conventional Commits](https://www.conventionalcommits.org/es/): `feat: add area filter`, `fix: footer link`.
4. Abre un pull request hacia `main` rellenando la plantilla.
5. Alguien del equipo lo revisará. Puede que te pidamos cambios: es parte del proceso, no algo personal.

## Normas del código

- El código (variables, funciones, commits) va en **inglés**. Los textos que ve el usuario van en los archivos de traducción, nunca escritos a mano en los componentes.
- Nada de claves, tokens ni contraseñas en el código. Usa variables de entorno.
- Si añades algo nuevo, comprueba que no rompe lo que ya funciona.
- Cada repo puede tener su propio README con normas extra: léelo antes de empezar.

## ¿Primera vez contribuyendo?

Busca issues con la etiqueta `good first issue`. Si te atascas, pregunta en el Discord: nadie nace sabiendo.
